# 固定核心与可选机制的边界

完整可执行集合是：冻结的源端准备 + 下述固定核心 + corelib.json 中启用的可选机制。
只给出可选开关数量，不等于给出完整语义规则数。34 项 USED_RULES 是产物中的使用证据，
118 项 ALL_RULES 是历史审阅条目，两者都不是本次可执行配置。

## 固定核心（本轮没有逐项消融，不能宣称已经最小）

| 部分 | 本配置保留的行为 | 对照旧清单 |
|---|---|---|
| 源端准备 | 依赖闭包、透明性和 quality 元数据、声明分类；嵌入证明抽取及源内核重检查 | E01–E07、E11、E13 |
| 声明输出 | 计算定义生成 def / opaque，普通定理生成陈述；显式保留未装配前提 | E03、E08–E12 |
| 基础项 | 变量作用域、Π、λ、let、应用、引用、cast、SProp → Prop | T01–T05 |
| 数据类型 | 单体归纳、非均匀参数、受支持记录／嵌套形状、非递归 coinductive | T07–T11 |
| 消去与递归 | 依赖 match、非均匀 match、结构递归、索引及变化参数处理、互递归、递归暴露、course-of-values、accessibility、cast 修复 | M01–M10、M12–M13 |
| 基础宇宙 | 原生事实、sort 读取、参数化、类型统一及合法默认、模板和显式多态实例、引用检查、一般性检查、按引用自动产生隐含参数 | U01–U11、U14、U15 的自动参数化部分、U18、U20、U22–U23、U30、U34–U35 |
| quality | 原生绑定、Prop／Type 模板族、有限 SProp／Prop／Type 分支及源注解分派、全部分支检查 | Q01、Q03–Q07 |
| 表示转换基础 | 配合已启用提升策略进行应用、函数、字段和嵌套转换；转换结果始终检查 | L02、L04–L09 |
| 原语 | 4 个原语类型和 61 个操作的固定语义模型／适配；不是 nat/eq 的原生替换 | N01–N06；完整映射见 results/USED_RULES.md |
| 验收和调度 | 依赖完整性、源端检查、Lean kernel、公开陈述一般性、源 universe 界限、独立 consumer / audit、失败回滚及资源上限 | V01、V03–V09、S01–S05 |

没有进行外部证明装配（E14）；nat/eq bootstrap（T06）为空，不能恢复旧映射。

## 开关语义

开关控制具名的实际转换入口，原代码保留以便全开启回归和复现实验。
无开关可以跳过 kernel、独立审计、P0、陈述一般性、源界限或根覆盖检查。
关闭入口时，其他启用入口仍可尝试；不存在按某个根的名字直接返回旧译文的规则。

特别注意：
- implicit-discovery 只关闭 R3G 的预先 discovery pass；普通转换中由引用得到的隐含参数仍属于固定核心。关闭它不表示整个 R3G 消失。
- joint-levels 关闭显式 P2 重试；基础求解器和已有联合约束仍保留。
- fact-interpretation 关闭可选 R2F 解释，包括 inductive 的 sort_interp；R0/R3 的事实检查仍保留。
- alias-delta 关闭 erasingPoly 别名重试；类型检查中的定义相等及结构递归暴露不是这个开关。
- source-compute 关闭用于重试正文／类型的构造器驱动源计算；资格分析仍可分析源声明。
- prop-lift / type-lift 控制相应声明重试，已生成表示的必需参数／结果适配由固定转换核心完成。
- wf-obligations 关闭需显式良基证明参数的重试；结构递归与已有 accessibility 证书构造不因此停用。

单项删除失败的意义：在最终剩余集合、同一固定核心、同一预算和同一验收条件下，
少此入口不能通过该见证。失败原因区分翻译失败、独立审计失败和前提／状态回归。
这不是对所有其他算法或其他规则分组的必要性定理。
